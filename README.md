## Дипломный проект. Задание 3: Веб-приложение

### Автотесты для проверки программы, которая помогает заказать бургер в Stellar Burgers

### Реализованные сценарии

Протестирована функциональность в Google Chrome и Mozilla Firefox. 

### Структура проекта

- `pages` - пакет, содержащий тестируемые страницы с Page Object
- `tests` - пакет, содержащий тесты, разделенные по классам.
- `allure_results` - пакет, содержащий отчеты
- `locators` - пакет, содержащий используемые локаторы
